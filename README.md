## My Hello Word +
# Explanation
    This is my code for the Hello World + assignment. What it does is that it prompts the user how many times
    they want the phrase "Hello World" to be printed in the screen. Once the user puts a number and presses the "Run" Button
    it will print the phrases.

# How to run it
    First you will have to open the "helloplus" folder in VScode, and then it will give you a link of where the program is running.
    You can copy and paste it on your desired browser, or you can use Ctrl+Right_click to open the page on VScode.
